🔐 PassGuard – Password Strength Analyzer & Generator

A modern cybersecurity tool that analyzes password strength in real-time, detects vulnerabilities, calculates entropy, estimates crack time, and generates cryptographically secure passwords.

📌 Overview

PassGuard is a web-based cybersecurity application designed to help users create and evaluate strong passwords.

The application provides:

Real-time password strength analysis
Entropy calculation
Vulnerability detection
Pattern recognition
Secure password generation
Password security recommendations

✨ Features
🔍 Password Analyzer
